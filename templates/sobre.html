Sobre o Projeto

Este site apresenta alguns dos principais pontos turísticos do Litoral Paraibano, construído com Flask, Bootstrap e integração com IA (Gemini).

Objetivo do Projeto

O objetivo é demonstrar uma aplicação web simples utilizando Flask, integração com uma API externa (Gemini) e a criação de páginas temáticas. Além disso, apresentar informações turísticas de forma organizada e visualmente agradável.
